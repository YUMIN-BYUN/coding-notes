# Python Day 07 - NumPy Basics

## Topics
- NumPy Introduction
- NumPy Arrays
- Array Creation
- Indexing and Slicing
- Vectorized Operations
- Broadcasting
- Basic Linear Algebra

## Learning Objectives
- Understand the purpose of NumPy and the `ndarray` data structure.
- Create arrays using `array()`, `zeros()`, `ones()`, `arange()`, and `linspace()`.
- Access and manipulate array elements with indexing and slicing.
- Perform efficient element-wise vectorized operations.
- Understand broadcasting between arrays of different shapes.
- Perform basic linear algebra operations including matrix multiplication, transpose, determinant, and inverse.
