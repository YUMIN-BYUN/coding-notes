# C++ Day 12 - STL Advanced

## Topics

- std::priority_queue
- Lambda Capture
- std::find_if
- std::count_if
- std::transform
- Object Containers

## Learning Objectives

- Use `std::priority_queue` to process data by priority.
- Understand value and reference capture in lambda expressions.
- Find elements based on conditions using `std::find_if`.
- Count elements based on conditions using `std::count_if`.
- Transform container elements using `std::transform`.
- Combine classes with STL containers and algorithms.
