# C++ Day 06 - Classes

## Topics

- Classes and Objects
- Member Functions
- Constructors
- The `this` Pointer
- Static Members
- Destructors

## Learning Objectives

- Understand how classes are used to define user-defined types.
- Implement member functions to encapsulate behavior.
- Initialize objects using constructors.
- Use the `this` pointer to distinguish member variables from parameters.
- Share data across objects with static members.
- Understand when destructors are called and their purpose.
