# C++ Day 05 - Struct, Enum, Namespace & Multiple Files

## Overview
This lesson introduces how to organize larger C++ programs using `struct`, `enum`, `namespace`, and multiple source/header files. You will also learn header guards, `#pragma once`, and the C++ compilation process.

---

## Topics

- Struct
- Enum
- Namespace
- Declaration vs Definition
- Header Files
- Include Guards
- `#pragma once`
- Multiple Source Files
- Compilation & Linking

---

## Learning Objectives

After completing this lesson, you will be able to:

- Create and use structures to group related data.
- Define enumerations for meaningful constant values.
- Prevent naming conflicts using namespaces.
- Separate declarations and implementations using header/source files.
- Protect header files with include guards or `#pragma once`.
- Understand how multiple C++ files are compiled and linked together.
