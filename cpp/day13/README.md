# C++ Day 13 - File I/O & Exception Handling

## Topics

- File Output with `std::ofstream`
- File Input with `std::ifstream`
- Append Mode with `std::ios::app`
- File Parsing
- Exception Handling with `try` and `catch`
- `throw`, `std::runtime_error`, and `std::exception`

## Learning Objectives

- Write data to files using `std::ofstream`.
- Read data from files using `std::ifstream`.
- Append data without overwriting existing file contents.
- Parse structured file data into variables.
- Handle exceptions using `try` and `catch`.
- Throw and process standard exceptions using `std::runtime_error`.
