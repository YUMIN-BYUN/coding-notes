# C++ Day 15 - Two-Body Gravity Simulation

## Topics

- Two-Body Gravitational Motion
- Particle Class
- Position, Velocity, and Acceleration Structures
- Relative Position
- Gravitational Acceleration
- Explicit Euler Method
- Numerical Time Stepping
- CSV Output
- Orbit Visualization

## Learning Objectives

- Model two interacting particles using C++ classes and structures.
- Calculate gravitational acceleration from relative position.
- Update particle positions and velocities using the Explicit Euler method.
- Perform a numerical two-body simulation over multiple time steps.
- Export simulation results to CSV for trajectory visualization.
